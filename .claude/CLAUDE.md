## Trabalho persistente

Sempre verifique:

`.claude/work/CURRENT.md`

Se existir uma tarefa com `STATUS: ACTIVE`, leia os arquivos relacionados e retome o trabalho de onde parou.

Use:
- `.claude/work/SALES_FORCE_PLAN.md` para o plano;
- `.claude/work/SALES_FORCE_PROGRESS.md` para progresso;
- `.claude/work/SALES_FORCE_AUDIT.md` para auditorias.

Antes de continuar:
- verifique a branch;
- execute `git status`;
- analise alterações existentes;
- compare o progresso documentado com o estado real do código.

Não reinicie trabalho já concluído sem necessidade.
