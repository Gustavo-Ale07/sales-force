Restrições operacionais OPS-6

  • Operado por equipe interna pequena com apoio de IA; sem exigir equipe de DevOps.
  • Mínimo de componentes; serviços gerenciados quando reduzem risco.
  • Todo procedimento com runbook; recuperação nunca depende de conhecimento não documentado.
  • Produção preferencialmente no Brasil; LGPD com justificativa se fora.
  • Uma instância de API e uma de worker por ambiente inicialmente; transações longas proibidas em tabelas sincronizáveis.
