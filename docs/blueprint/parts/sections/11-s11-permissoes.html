Permissões

P-20 · P-21AUTH-4 · matriz §8.2

Permissão de ação (o que o perfil pode fazer) é separada de escopo de dados (sobre quais registros). Permissões nomeadas recurso.ação (ex.: order.approve, account.export) agrupadas em perfis; o admin ajusta (RF-IAM-6). Autorização sempre no servidor (P-21, APROVADO).

✔ permitido — não permitido ✖ proibido explicitamente borda verde célula coberta por decisão aprovada fundo laranja decisão pendente

Proposto (security-model §5.1): novas permissões nascem negadas. Até isso ser aprovado, nenhuma permissão nova é concedida a um perfil sem instrução explícita.
